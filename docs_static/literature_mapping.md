Equilibration: [R4] Higham–Pranesh–Zounon 2019 motivates the two-sided power-of-two row/column scaling used by `*_twosided` methods (E3); our default heterogeneous method uses only a global power-of-two normalization to max|A| in [0.5,1) and counts FP16 overflow/subnormal conversion events. Safe conversion does not prove safe elimination; failures are recorded as such.
